# Audio asset QA — 0.5.0（23）

本目录的这份记录只说明本轮音频资产的来源、编码和信号验证，不代表应用已经构建、安装或完成真机验收。

已准备 3 首背景音乐与 12 个交互音效，合计 7,457,664 字节（约 7.11 MiB）。运行文件均为 44,100 Hz 的 CAF IMA4；背景音乐为立体声，音效为单声道。它们使用本项目新编写的乐谱与离线合成器，不包含下载歌曲、第三方采样、人声或真实动物录音；猫叫是卡通化的音高与共振峰合成效果。

| 背景音乐 | 解码时长 | RMS | 峰值 |
| --- | --- | --- | --- |
| `bgm-home.caf` | 49.230658 秒 | −23 dBFS | −9.16 dBFS |
| `bgm-work.caf` | 39.999274 秒 | −23 dBFS | −9.57 dBFS |
| `bgm-sleep.caf` | 64 秒 | −27 dBFS | −13.28 dBFS |

资源生成时已把全部 15 个 CAF 解码回 PCM，检查采样率、声道、帧数、峰值、RMS、削波、静音窗口及循环接缝。全部文件没有削波；三首音乐没有静音的 100 ms 窗口，解码后末采样与首采样的幅度差均为 0。循环乐句和混响尾部在同一循环内回绕，边缘使用 3 ms 安全渐变，不添加静音引导帧或整曲淡出。音效允许自然的短静音尾部；上述“无静音窗口”要求只用于背景循环。

本次 QA 另行核对了完整文件清单、当前字节数、SHA-256 与 CAF 格式头，全部与源清单一致。CAF info 元数据只有近似时长与原始 PCM 位深，没有作者、设备标识、用户名或本机路径。每个文件的指标与验证边界见 [资产验证记录](audio-assets-verification.json)。

**主观听感尚未验收。** 已另行准备短试听，但生成试听与数值检查不等于完成扬声器/耳机试听，也不等于音乐审美、猫叫自然度或游戏内音量平衡已经获认可。此处不记录构建、签名、安装、真机启动、事件触发时机、系统静音或中断恢复的结论；这些属于独立的整合验证。
