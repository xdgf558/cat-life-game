# 0.14.1（53）邻里、新手指引与图鉴 UI/UX 重制

状态：本地开发、定向验证与 Release 归档完成，等待 PR 审查，暂不上传 TestFlight。上一版 0.14.0（52）随 PR #16 合并，但未上传；50–52 均未单独发布，最后已上传的是 0.13.3（49）。候选更新历史只列 53、49、44。内测、外测、邀请与审核分发仍由用户手动完成。

## 本轮范围

- 按 `design_handoff_catlife_0.14.zip` 重做邻居街：紧凑人物卡、今日拜访进度、分段好感与关系阶段、喜好提示、固定拜访和送礼按钮。奖励明细默认收起，正文独立滚动，操作区保持可见。
- 送礼先选礼物，再明确确认；选择和取消不消耗库存。缺货时可进入补货页，购买后返回挑选，不自动赠送。邻居详情、礼物商店和底栏保持明确返回路径。
- 关系升级在保存成功后展示庆祝卡和实际到账的金币、用品数量。回执在同一时间完成同步后计算，排除同时结算的工资，并反映钱包、背包容量截断；保存失败不展示成功回执。离开页面后仍保留全局成功提示，震动继续由已有音频控制器统一处理。
- 新手指引改为在真实首页与底栏入口上聚光提示，卡片正文独立滚动，保留上一步、下一步、跳过与前往实际页面。跳过或暂时前往页面后可继续原步骤，设置可重新开始；指引捷径只导航，不消费资源。自动开启仍只面向新建存档，旧档不自动弹出，成功导入结束当前指引。
- 图鉴紧凑展示五种猫咪的收集状态，为暹罗猫与银渐层标出新伙伴，只有多页结果才显示分页。使用现有猫咪、邻居和礼物美术，保留房间及猫咪大小。
- 三语文案、较大辅助字号、减少动态效果和可访问性标识随布局调整；保存错误提示继续由当前展示层负责，避免礼物弹层与底层页面重复呈现。

## 回归中发现的问题与修正

- `safeAreaInset` 之后的父级可访问性标识覆盖了钱包和按钮的标识，导航栈还暴露了多余的系统返回按钮。已调整标识归属和返回导航，保留实际控件的独立可访问性入口。
- SE 最大辅助字号下，固定头部和底部操作区挤压了正文空间。固定导航区域现将字号上限设为 `xxxLarge`，正文继续使用玩家选择的辅助功能字号并独立滚动。
- 关闭引导后，首页实际触摸可以操作，但动态切换底层可访问性隐藏状态导致整页在可访问性树中不可点击。已取消底层的动态可访问性隐藏；聚光层使用独立 `contain` 容器和 `modal` 语义，全屏遮罩拦截底层触摸。
- 领养提醒可能挡住邻居页的返回操作。现于邻居页面暂缓展示，仍保留待展示队列，离开邻居页后可继续提醒。

- 小屏底部高亮框将描边也纳入边界保护；英文最大辅助字号正文较长，自动化增加实际滚动次数，仍检查整按钮可见、可点，未跳过检查或缩小正文。双屏五步及 SE 三语最终通过。
- 人工看图发现礼物喜好徽标在最大字号遮住名称，现改为独立一行；粉色按钮的阴影改绘制在背景，避免文字重影。最终截图已人工核对。
