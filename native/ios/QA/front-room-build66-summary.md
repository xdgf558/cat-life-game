# 0.21.1（66）· 正面房间与初始布置调整

当前为未发布候选。基线为已合并的 0.21.0（65），本轮尚未合并或上传 TestFlight，未安装真机、读取或改写真机存档。网页版本保持独立。本摘要仅保存实现范围与可公开的验证结论；原始日志、截图和完整测试产物另存，不纳入 PR。

## 完成范围

- 默认正面视角将地面边界连续映射到较平正的矩形地板，以完整墙面、窗户和地板形成房间；左右固定视角继续保留原有方向展示。现有近看、视角切换和楼层入口保持。
- 保留猫咪与家具的源节点尺寸、原始保存坐标、寻路和碰撞规则。正面显示坐标与触摸坐标使用同一套可逆映射，墙饰采用对应的墙面换算；不是把新屏幕坐标写回旧档。
- 家具拖动按屏幕中的实际抓取偏移计算目标，避免非线性投影下手指与家具脱离。全屋取景纳入高件家具的图像范围，编辑选中状态下固定取景，退出编辑后重新取景，避免房间跟随高件上下跳动。
- 二楼保留紫色墙面氛围，陪伴标记、名字、需求气泡和猫咪预览继续使用可见投影位置。
- 新档默认家具重新分布，高件靠后，中间与前方留出照顾、休息和移动路线。食盆仍沿用原始默认坐标，不改照顾消耗或家具数量。

## 旧档保护与 schema 13

本轮没有新增玩家进度字段。schema 13 为一次性初始布局调整建立明确边界，避免旧客户端误读或反复重排。

仅在以下条件全部满足时，旧档默认家具才改用新初始位置：源版本小于13；地面食盆仍在原默认位置；未解锁二楼；全部九件初始家具的位置、楼层、类型和普通朝向准确匹配冻结的旧布局；没有额外已摆家具；任何猫都没有正在休息、专属角落或未关闭的休息观察；没有活跃的一起玩会话。匹配与数组顺序无关，迁移保留数组顺序；未摆放的新购家具可以保留在背包，不阻止迁移。

移动、镜像、收纳、替换类型、额外摆放、改碗或已解锁二楼的布局原样保留。正在使用的休息位置、角落和观察不会因本次重排失效。已经是 schema13 的存档不会再重排，玩家自行恢复成旧初始布局也照样保留。既有 schema6 坐垫迁移和旧档缺省布局使用冻结常量，不随当前默认位置变化。

迁移测试覆盖完整旧布局、乱序、未摆放购买、经济与任务进度、后台打工、任一猫的休息与角落、未关闭/已关闭观察、活跃陪玩、二楼、定制布局、导入导出和重复读取。固定的 v7/v8/v10 邻里账本校验保留，另补 v11 活动及字面 v12 习惯回执保存用例，不放宽生产校验。

历史失败与修正单独保留：

- 早期正面原型裁到靠后高件猫爬架，现全屋取景纳入真实家具图像边界，家具原始尺寸不变。
- 初始 Core 执行的8个新测试因共用13字符房间名超过既有12字符上限而产生69条连锁断言；改为合法名称并增加前置校验后通过，未放宽产品校验。
- 新默认位置校准期间发现墙饰边界、食盆通行与视觉交叉不满足约束，调整位置后由最终341项 App 全量验证；临时探针未保留为正式代码。
- UI 首轮把屏幕中的场景草稿误当成已保存布局；另一次点击实际正确选中了猫爬架，旧的无障碍测试预期却仍按其他实例判断。后续新增的无障碍框点击辅助也未能找到可点击区域，已移除该辅助，墙饰流程以真实当前选中的墙饰实例继续验证。生产命中规则保持不变，未新增隐藏测试按钮。
- Pro 最后一口测试的旧公共断言要求房间等于402pt整屏宽度，当前独立房间舞台实际为382pt，因此在进食前失败。共享断言已改为与真实舞台范围一致，并检查舞台、照顾栏与底栏的关系；进食、嘴与碗接触、帧采样、库存及持久化断言全部保留。修正后的最后一口单项已通过，原失败批次仍保留，不改写为整批通过。
