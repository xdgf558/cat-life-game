# 0.6.1（29）用品价格与房间缩放

用品、家具和装备统一在名称下显示金币价格，用品保留一键购买；金币不足时按钮禁用并显示原因。升级房间后可双指缩放，从完整房间全景到正常视角的 1.6 倍；空地拖动、家具摆放和找到猫咪复位均沿用同一镜头坐标换算，家具存档和世界尺寸不随缩放改写。

35 项 App 单元测试通过，其中 5 项为新增缩放检查。32 个 Core 输入哈希与上一版一致，沿用 168 项通过证据，本轮未重跑核心测试。六个相关 UI 方法在 SE／Pro 上共执行 12 次：9 次通过、3 次早期手势起点被 HUD／照料面板遮挡的失败，最终五次执行全部通过。真实双指捏合、边界、布置拖动、喂食、寻找猫咪、冷启动、购买扣款、金币不足和更新页均有对应断言。

最初 XCTest 根据整个房间无障碍框，从被上层控件遮住的角落起手。导出的触点坐标及镜头仍为 0.625 的诊断确认第二次捏合未被房间识别。随后仅增加 DEBUG 非触控测试靶区，将公开 XCTest 双指事件放在可触摸区域；未改变生产缩放算法或放宽断言。发布包已确认不包含靶区及测试夹具。

构建缓存均在外置硬盘。这里只保留脱敏结果和六张必要截图，截图使用 Git LFS；完整结果束、日志、安装回执和真实存档留在本地临时目录。真机交付状态以 verification.json 为准。未全量重跑历史 UI、iPad、大字号和真实 VoiceOver；真机手感及长时间体验待玩家验收。
