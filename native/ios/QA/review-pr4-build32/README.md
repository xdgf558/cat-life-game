# PR #4 审查修订 · 0.7.1（32）

本轮在 0.7.0 上修复审查问题，不改变领养价格、升级条件、房间与猫的显示尺寸。源码、单元测试、签名构建和交互回归已完成。已覆盖安装，首启前 4,241 字节存档逐字节一致；用户解锁后已核对新版进程、schema 2 和身份／物品／布局保留，玩家玩法验收仍待反馈。最终状态以本目录 `verification.json` 为准。

| 审查项 | 修订与边界 |
| --- | --- |
| 存档版本 | schema 升至 2；schema 1 解码时保留房间、装备、外观、陪伴猫、工作与休息，再由成功保存落盘。版本检查在业务字段解码之前，未来格式不恢复旧备份、不覆盖主档。新客户端显示明确的升级提示。已发布旧客户端有未来格式拒读保护，但其通用错误文案无法追溯修改；尚未被新版成功保存的 schema 1 文件也无法追溯获得回退保护。 |
| 切猫图集 | 欢迎页后台计算两种猫、14 张动画图集的像素锚点，纹理创建保留主线程；只读序列按素材共享，反复切换和新角色实例不再扫描。测试核对注册次数、纹理身份、8 帧及奶牛猫独立爪点。绕过欢迎页直接构造场景仍保留一次同步注册的恢复路径；未测旧真机毫秒耗时。 |
| 扩建时消失 | 后台规划完整新世界，等待期间保留安全的旧房间、猫和食盆，成功后一起替换几何、家具、猫位置、食盆和导航。初次加载仍等待首个安全结果；进食和休息不被升级强行取消。测试覆盖快速连续升级、尺寸变化、后台恢复、家具占位和规划时切猫。 |

| 无变化的恢复写盘 | 若没有需落盘的业务变化，重试只读校验既有存档，并在同目录写入、读验、删除小探针，不重写主档或轮换备份。有待结算的工作／休息仍走完整事务，失败的购买与喂食不自动重放。探针不能保证下一次更大写入必然成功，后续真实失败仍保留提示与重试。 |
