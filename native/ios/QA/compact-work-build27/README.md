# 紧凑打工页 — 0.5.4（27）

2026-11-03。本轮调整打工页面的信息布局和导航，23 项 App 单元测试通过，大小屏最终 6 次定向 UI 回归全部通过。0.5.4（27）已覆盖安装，安装前后 3,940 字节存档逐字节一致；手机解锁后正常启动与当前安装对应进程已确认，玩家体验验收待反馈。

打工首页保留等级经验、体力心情摘要和当前工作卡片；卡片显示时长、报酬、消耗以及开始按钮或倒计时。选择职业、职业详情、休息恢复和已有的最近结算各有明确入口。完整说明与休息控件进入独立页面，返回后回到打工首页。

职业目录每页最多 4 项，支持按当前语言显示的职业名称搜索，以及全部、已解锁、未解锁筛选。搜索忽略首尾空白、字母大小写与重音；修改搜索或筛选会回到第一页，没有结果时显示空状态。未解锁职业仍可查看详情，但不能选择。详情展示职业说明、实际时长、金币与经验奖励、体力与心情消耗、穿戴加成和解锁条件。工作进行时沿用开工时保存的报价，浏览或选择下一份职业不改变正在进行的工作。

`WorkDestinationView` 负责这些页面与导航，`CareerDirectory` 只处理展示用筛选和分页。当前实际职业仍为 5 种；101 项目录属于分页单元测试输入，不是新增 101 种职业，也不是 101 项真实界面的性能验收。Core、Store、Scene、Audio 的 45 个既有源文件未改变，报酬、消耗、计时、离线结算、休息互斥及存档规则沿用上一版；房间与猫咪尺寸不变。
