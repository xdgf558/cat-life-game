## 已实现

- 五猫风格/休息/节奏按稳定角色 ID 配置，不随改名、语言、外观或重启变化。起手复用已有表情；节奏决定是否扑抓，不改变数值。
- 陪玩入口明确分为快速陪玩与一起玩。后者使用独立、有界的约 20 秒 SpriteKit 小场景，支持拖动及两种点按轨迹；过快时停下观察，减少动态效果使用静态表情与文字。没有整间房的物理追逐或新动作素材。
- 原快速陪玩与互动共用内部 `applyPlay`，普通互动首次有效输入才消费一次、结算一次、计任务一次；只打开即退出不消费。回执显示实际、经上限裁剪后的变化。
- 免费教程按整份存档一次，绑定教程猫与固定观察资格 ID。两种节奏均可试到；中断可继续，但重复免费教程不能制造两条独立线索。教程不扣资源、不发数值、不计任务；确认陪玩偏好至少再有一次付费会话，零玩具沿用原商店补货。
- 休息沿用原路径、恢复量及猫窝 12 秒/地垫 9 秒规则。玩家发起、房间前台可见的到位才附加观察元数据，Core 在自然到期时生成线索或中性的对比提示。自主休息、未到位、无路、提前打断不增加进度。
- 每偏好最多两条独立匹配线索；对比提示不计数、不惩罚。四张有限回忆自动生成，无领取奖励或问号打卡格；老猫高亲密不降级，旧档不补造经历。
- 有效休息后在家具旁显示可忽略的小角落选项，避开实际 HUD、照顾列和视角工具；大字内容可滚动，档案也可选择。非偏好家具同样可选。收纳取消角落，已得回忆保留。
- 保存成功才发布状态和扑抓反馈。会话固定猫 ID/会话 ID；后台、冷启动、换猫及导入备份结束当前会话，迟到输入不能串写；失败的结束请求保留原捕获时间，随后续事务重试。
- schema 1–11 仅补空的新记录；当前 schema 缺失或损坏的新字段拒绝读取，不静默重置。导入未来时间检查包含习惯、回忆与互动回执。简/繁/英与版本历史同步。
- 可选本地观察模式默认关闭，最多 2,000 条内部 ID/事件/时间/控制记录，不含自定义名字、图片或设备标识；主动导出/清空，无网络上传。测试模式先问玩家观察，再按“继续”揭示文字结论。日志错误不影响游戏存档。

- **App 全量 317 项通过**：`unit-final-4`，iOS 27 / iPhone 17 Pro。包含真实 SpriteKit 帧的五猫完整/对比反应、失败写入、后台期间悬挂保存、冷启动、日志隐私与可见性。随后回执区分猫咪/玩家心情，并让工作预验证早于会话到期变更；最终 Core 全量和 `scope-final-11` 的 4 项、`app-final-scope-15` 的 15 项相关 App 定向测试再次通过。

早期失败均保留：首轮 App 314/315 通过，日志隐私测试使用超出既有 12 字符上限的名字，已修正测试输入；下一轮 316/317 通过，导入用例将毫秒归档与归档前亚毫秒 Date 做严格比较，已改为与归档预览比较，业务断言不放宽。最终 317 项全量已通过。

房间回归另找到三点触控扩展区抢占邻家具可见图像的原有问题；已先通过独立红测重现，再改为优先真正图像框，只有未命中图像时才用 44pt 辅助区，原布局/物理尺寸不变，相关 App 回归通过。旧 UI 还使用可能早于相机稳定的缓存锚点，现改为读取实时显示代理的框再真实点击，不使用隐藏玩法按钮或直接发放进度。

iOS 27 仍报告现有 `AVAudioSession` 同步激活可能阻塞主线程的 SDK 警告；本轮没有扩大为音频系统重构，也不据此宣称旧机帧率/耗电通过。

原始日志、xcresult、截图与录像保留在 Git 外的 `cat-life/build63-qa` 编译缓存目录；仓库只保留摘要。
