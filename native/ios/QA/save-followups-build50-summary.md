# 0.13.4（50）存档导出与时间校验

候选修复版，未上传 TestFlight、未安装真机。独立于后续 0.14.0 邻里与新猫功能。

## 改动

- 导入预览与最终提交都检查进度时间，超前超过 24 小时明确拒绝并保留当前进度。编码及导出原件不受此限制；24 小时以内沿用现有时间规则。
- 普通备份在本机保存失败时仍能导出有效内存时间线，保存失败和重试状态仍保留，不把失败操作计入进度。系统文件导出直接使用内存文档；本地分享附件生成失败不再阻断“存储到文件”。
- 与按相同时间自然推进的全新存档比较，忽略语言、声音、人物形象和名称偏好。只有这些偏好的新设备不误报进度倒退；照顾、布置等真实变更仍显示提醒。
- 保持 schema 6、备份格式 1、5 MB 限制；较新版本原件保护和导入前恢复点规则不变。

## 验证

10 项 Core 备份定向测试通过。App 首轮 139 项中 138 项通过，1 项新测试因使用超过 12 字符的名字而未进入写盘路径；改用合法名称，并加入实际写盘尝试断言后，12 项 Store 备份测试全部通过。产品逻辑未为该测试放宽校验。

小屏模拟器两项 UI 回归通过：真实 Files 导出、重新选择、预览和恢复点流程，以及当前版本和最近三次更新页面。Debug App 构建及 git diff --check 通过。原始日志和 xcresult 保留在 Git 外，PR 只提交此摘要。

## 边界

真实磁盘满、iCloud/第三方文件提供方和跨设备导出仍需真机验收；导出备份并不代表本机自动保存已经恢复。不可用恢复点丢弃、带日期文件名/专用文件类型、备份签名和正式 App Store 更新入口属于后续独立事项。网页版无改动。
