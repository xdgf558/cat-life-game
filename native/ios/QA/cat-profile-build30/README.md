# 0.6.2（30）猫咪档案与改名

猫町改为每页最多 4 张猫咪卡片，点卡片进入单猫六项属性，再通过铅笔进入改名页；首页头像和房间猫也可直接打开当前猫的档案。详情始终按猫 ID 读取最新数据。名字支持 1–12 个可见字符、中文与表情，保存成功后才更新列表和首页；取消不改名，失败保留草稿且可重试，恢复默认仅清除选中猫的自定义名字。

新增可选 customName，旧 name 与 schemaVersion=1 保留。旧档缺失该字段可正常载入，坏的名字覆盖只恢复该字段，不回退整份游戏进度。显式自定义“小橘”也保持原文，默认名字仍可本地化。174 项 Core（16组）、40 项 App 以及 8 次 UI 执行全部通过；UI 覆盖六个方法，包含 SE／Pro 分页、独立改名、长名字、取消／重置、三语、写盘失败重试、重启、最近三次版本记录和真实休息后的属性读取与失败退出恢复。
