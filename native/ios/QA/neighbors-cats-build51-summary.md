# 0.14.0（51）邻里拜访与两只新猫

状态：候选版，Release 归档已构建；尚未安装真机、上传 TestFlight 或分发测试。基于独立存档修复 PR #15；本版 PR 的基线为其分支，避免重复审查。网页版没有改动。

## 范围与存档

- 四位本地 NPC、每日首次拜访、重复聊天、四种可购买礼物、喜好加成、每日一次赠礼和五阶段好感度；20/40/60/80 点的阶段奖励与回执一起保存。
- 商店与背包共用紧凑礼物入口，邻居详情收起奖励明细，支持三语与辅助功能字号。新邻里任务沿用现有分页与领取隐藏规则。
- 暹罗猫可可与银渐层霜糖分别有头像、静态图和七套八帧动作，保持原有猫咪尺寸、导航及家具规则。领取后切换、各猫独立状态、图鉴和医院使用同一目录。
- schema 7 为原生 1–6 版补全邻里与礼物数据，保留原进度；当代字段缺失或无效仍拒绝。历史未知邻居、礼物及奖励回执保留，避免以后下线内容导致整档不可读。邻里每日限制与任务共用日期账本，跨时区和回拨不重复刷新。
- 保存成功后才发布扣费、库存、好感和奖励。离开邻里页面后完成写入仍有全局提示；成功提示优先于领养横幅。领养提醒从邻里页打开图鉴时显式清理邻里路由。

为“新增邻居却遗漏存档迁移”的 P2 增加 schema 7 与固定四个邻居 ID 的绑定测试；同时用固定的 v7 邻里账本实际解码，检查原有好感、每日次数、累计次数和阶段奖励回执完整保留。该账本不会随目录或全新存档默认值自动增加邻居。以后修改 schema 或目录时必须审查迁移，再更新绑定断言，并保留这份历史账本验证。

本轮临时向目录添加第五个邻居而不修改迁移，单独运行新测试，确认目录断言和 v7 解码均失败；随后恢复目录，完整 336 项 Core、33 个 suite 全部通过。此次仅修改测试和文档，没有更改运行代码、schema、版本号或构建号，未重建 App 或重跑 UI。上方 App/UI/签名结果属于原候选归档的验证记录；本轮原始日志仍放在仓库外。

复审中“五只猫同屋”需更正：当前可拥有五只猫，但房间只有一个 `CatActor`，只渲染并寻路当前陪伴猫；切换会结束旧猫休息和动作，不存在五只猫同时争抢休息点。全部猫的数值同步及真机表现仍需按原验收计划检查。

新增 P3 后续记录：满好感改用“已是挚友”等文案并在赠礼前说明零增长；阶段奖励提示列出实际到账数量及上限截断；新设备超过一天未操作时的备份比较可能因健康追算窗口产生额外提醒。本次未改这三项产品行为。
