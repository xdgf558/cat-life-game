# 可可与霜糖素材 · 0.14.0（51）

使用内置 image_gen，参照现有猫咪的姿态、构图和卡通质感，为暹罗猫“可可”和银渐层“霜糖”各生成十张透明 PNG。可可采用奶油色身体、深色面罩和耳爪尾、蓝色眼睛；霜糖采用银白渐层毛色、绿色眼睛和粉色鼻耳。原有三只猫的素材未覆盖。

运行资源位于 `../../CatLife/Assets.xcassets/cat-siamese-*.imageset/` 与 `cat-silver-*.imageset/`，通过 Git LFS 保存。每只猫包含头像、坐姿、进食静态图，以及 expressions、walk、rise、meal、play、rest、step 七套八帧动画；rest 为两列四行，其余动画为四列两行。最终 PNG 原样接入，没有脚本改色、抠图或拼帧。

生成约束为“只改变品种外观，保留对应帧的姿态、方向、数量、透明背景和留白”。初次 meal 结果因耳朵或胡须越过帧边界被弃用，最终以已修正排列的蓝猫 meal 为目标重新生成。完整提示词及只读像素分析随本次发布的外部美术产物保存，不重复加入源码。

两只猫分别测量进食第 2、3 帧的下唇或舌尖，以及 step 全八帧的前后爪和支撑基线，接入 SpriteKit 注册；继续使用原有显示尺寸和导航碰撞区域。`CatSpriteLibraryTests` 检查所有资源、正反方向的食物接触和上下家具的爪位；`CatAdoptionUITests` 覆盖实际喂食、玩耍、上窝、上垫及下地。像素校验不能代替这些运行验证。
