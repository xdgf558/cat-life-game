- 顶部固定两行：小家名称/等级与金币/体力；陪伴猫身份与切换提示、楼层、布置。移除独立“找到猫咪”“显示/隐藏照顾”入口，保留病猫就诊入口。
- 房间进入左右留白的圆角舞台，全屋在舞台可用范围内取景；暖色背景、地板厚度和下方阴影继续使用真实房间美术。相机/投影公式、猫与家具的物理尺寸及保存坐标不变。
- 舞台底部合并三视角、指示点和“近看猫名 / 全屋”；普通模式 0.45 秒淡出切换、淡入，减弱动态效果下直接切换。换层、离页和编辑会取消过时转场，恢复输入。
- 名字与需求合成头部气泡，预览其他猫时隐藏；常驻三等分照顾栏显示真实库存和需求高亮，编辑时改用家具托盘。原有高级用品确认、存盘成功才消费和单猫照顾规则保持。
- “我的猫咪”、档案与设为陪伴继续使用真实目录和存档；新文案补齐简体、繁体、英文。旧 UI 测试入口迁移到真实按钮和真实场景身体命中，没有添加替代产品操作的隐藏按钮。

## 设计对照与有意适配

参考 R1–R7 按相同视角/模式与原生运行图组合对照。设计图为 390×845pt @2x；SE 为 375×667pt @2x，Pro 为 402×874pt @3x，Pro Max 为 440×956pt @3x。整图等宽比较并记录原始尺寸，不用裁掉溢出区域来宣称通过；忽略原型假设备边框、演示时钟和示意数值。完整 PNG、对照图、日志、xcresult、带哈希索引的 HTML 报告均保留在 Git 外的本版 QA 目录，不提交原始截图或设备日志。

保留现有默认正面视角（原型 R1 为右侧，R2 为正面）；原型 CSS 家具/两只示意猫替换为正式 3D 素材/真实猫数。近看目标约 70pt，沿用既有安全缩放范围，短屏可能被原上限夹紧，不改变相机数学以强制放大。原生点击范围至少 44pt，因此预览卡和控件比原型略高；极短舞台和辅助字号改用原生预览弹层。我的猫咪保留头像、名字、楼层、陪伴状态和原有操作，未新增原型目录行的毛色副标题。需求按现有可执行时机显示，不改 Core 需求阈值或为截图制造需求。
