# 多猫领养与陪伴切换 · 0.7.0（31）

新增奶牛猫“牛奶”。玩家等级 2、房间等级 2 且拥有 300 金币时可在猫町确认领养。领养只新增拥有记录；玩家在猫咪档案点击“带回房间”选择当前陪伴猫，名字、属性、照料、首页头像和场景外观随选择同步，并在重启后保留。

房间一次展示一只猫，家具与用品共用，六项猫咪属性、名字、时间衰减与休息记录按猫 ID 独立。切换仅在成功写盘后发布；保存失败不扣费、不增加猫、不切换，页面与保存状态条提供重试。切换时结算旧猫实际休息时间并取消旧路径、排队动作和回调。原生 schema 1 兼容缺少 appearance/activeCatID 的旧档，原名字和进度不变。

美术为 10 张内置 image_gen 生成的独立透明素材，包括 7 套各 8 帧动作；提示词与像素锚点校准位于 ArtSource/cow-cat-build31。房间、家具和猫咪显示尺度沿用已有配置。截图、脱敏摘要与校验清单在本目录，原始日志、测试结果包、设备标识和玩家存档不提交。
