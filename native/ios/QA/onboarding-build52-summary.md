# 0.14.0（52）新手指引候选

本轮在尚未发布的 0.14.0 上增加入门流程，等待 PR #16 复审；没有合并、安装真机或上传 TestFlight。51 仍是前一候选的验证记录，不作为 52 的执行结果。

## 行为

- 只有仓库本次真正创建新存档、且玩家从欢迎页点「进入小家」后，才自动开始五步图文指引：照顾、打工、用品、任务、猫町。
- 固定顶部跳过、底部上一步/下一步/完成，正文独立滚动；最大辅助字号隐藏重复装饰标题，保留完整内容标题。可前往实际页面；页面捷径只导航，不代替玩家消费、照顾、开工或领奖。未完成时保留继续入口，设置可主动从头重看。
- 本机 UserDefaults 保存进度，并按存档创建时间绑定。时间身份对齐磁盘日期的毫秒精度，避免首次创建后重启丢失步骤。游戏 schema 保持 7；本机没有对应指引记录的旧档/自动备份恢复不自动开启。成功导入后关闭并结束指引，导入失败保留步骤。
- 首页指引使用原任务入口的 44 点位置，完成或跳过后恢复任务入口；保持房间场景和猫咪尺寸。首页沿用紧凑 HUD 的字号边界，导览正文和其他页面继续支持最大辅助字号。
- 导览拥有自身保存错误横幅及重试弹窗，底层首页/猫町/玩家页不重复弹出；查看导览时暂停房间场景。复用已有卡通图片，无新增运行媒体或依赖。

- App 完整 162 项通过：包括新增 10 项本机进度测试和 5 项 Store 集成测试，覆盖新档/旧档/备份恢复、真实编解码后的身份匹配、续步、跳过重看、仅导航无资源变动与写盘、成功/失败导入、加载失败和损坏的本机偏好。
- 本轮未修改 Core，沿用同分支上一提交 336 项通过及邻居目录变更的反向验证；没有把该结果记作本轮重新执行。
- 三语共 1,147 个 key 与格式参数对齐；153 份运行媒体预检通过。工程新增六个源码/测试引用，没有整项目 ID 改写。
- 4 个新增 UI 场景均在 iPhone SE 和 Pro 模拟器通过：新档五步完整跳转与完成冷启、续步/跳过/设置重看、旧档不自动开启、三语最大辅助字号。实际断言入口不遮挡猫咪状态卡、按钮全框可见/可点、金币与猫粮保持，已人工检查截图。最后的辅助字号调整只复测其受影响分支，双屏三语均通过。

## 回归中发现的问题

首轮发现首页继续入口与猫咪状态卡重叠，已将继续入口移入原任务按钮槽，并加入实际几何不重叠断言。后续发现切到打工时隐藏首页仍暴露重复的继续入口，现仅在首页渲染该按钮。最大辅助字号自动化在长文滚动后曾提前退出导览，改为固定导航、正文独立滚动，并在辅助字号隐藏重复装饰标题，保留整按钮可见/可点击检查；最终双屏三语复测通过，初始失败日志仍保留。
