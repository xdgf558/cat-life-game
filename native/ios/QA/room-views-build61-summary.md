# iOS 0.20.0 (61) — Complete room and three fixed views

Prepared as one PR after the merged 0.19.0 (60). Not merged, installed on a physical device, signed for distribution or uploaded to TestFlight. The independent web game is unchanged. Physical-device acceptance remains with the user before a later release.

## Behavior and boundaries

- A complete cutaway shell follows the existing closed floor polygon, including its window/step notch. Warm wood, plaster and an arched window replace the cropped backdrop. Left/front/right buttons select three fixed projections (side angles ±18 degrees); existing furniture and cats remain upright sprites. This is a 2.5D presentation, not freely rotating 3D models or newly drawn furniture backs.
- Whole-room framing includes the walls and front edges and avoids the measured HUD and stairs. New scenes, upgrades and floor changes start at whole-room/front. Ordinary tab returns retain the current camera. Close view, Find Cat, one-finger panning and real two-finger zoom remain available, including level 1. Manual browsing suspends automatic follow until an explicit care/focus action.
- The scene runs one simulation. Reusable visual proxies read its current textures and poses; they do not copy actions, execute callbacks or render screenshots per frame. Camera/projection inverses translate taps and drags back to the original ground/wall coordinates. View changes do not spend supplies, rewrite layouts, alter collision sizes or add save fields; schema stays 11.
- Ground depth follows the selected view. Registered mouth/paw offsets and bed rims retain their calibrated local grouping during meals and furniture entry/exit. Exact visible frames take hit priority; only otherwise do nearest 44-point assist zones apply. Small neighboring objects no longer steal each other's exact image taps.
- Overview uses the compact cat card and an icon-only need bubble with its full accessible description. Near view retains the full need text. View tools and stairs retain at least 44-point touch areas; auxiliary overlay typography follows the existing HUD's maximum XXXL sizing, while full labels remain available to VoiceOver. Unavailable view directions/actions are disabled consistently.
- Original art, screenshots, recordings, logs and result bundles remain outside Git. Only three optimized runtime PNGs (Git LFS), a compact provenance note and this QA summary enter the repository.

## Verification

- App: a full run passed 281 tests. Final focused runs passed six renderer cases, the new real-clock bed/cushion contact case, two lifecycle cases and two camera cases. Across the full and focused runs, 283 distinct App cases have passing evidence; this is not a single final 283-test run. Core gameplay/schema code was not changed or retested in this task.
- Projection/camera/shell checks cover every `HomeCatalog` level, both available floors and two viewport sizes: full bounds, reversible ground/wall coordinates, zoom anchors/limits, edge scrolling and follow. Lifecycle regressions cover immediate viewport resizing while a rest exit defers world reconstruction and manual browsing without camera snap-back during care.
- Real SpriteKit clocks sample meal mouth landmarks in both facings and all three views, and entry/exit paw landmarks for both bed and cushion. Source positions remain unchanged by turning; each meal/rest/exit callback is issued once. Existing physical contact/obstacle tests remain in the full App run.
- The normal three-view UI journey passed on iPhone 16 Pro and iPhone SE simulators. It covers level 5-to-6 upgrade, all three views, whole/near, floor switching, actual upstairs furniture movement/save, ordinary tab return and cold relaunch. The final large-screen run repeated this journey after the overlay typography fix.
- Both sizes passed maximum accessibility text in Simplified Chinese, Traditional Chinese and English, with reachable separate view/stair controls and at least 44-point hit bounds. The small-screen initial-room real pinch/overview/near journey passed without unintended care or spending, followed by a real meal. The final expanded-room journey passed real pinch in normal and arrangement modes, a real furniture drag/save, exactly one meal with contact samples and no contact violations, Find Cat and cold relaunch with the saved layout and supplies.
- The existing hospital treatment-and-persistence UI journey also passed on the large simulator. Simulator screenshots of the final normal and auxiliary-font layouts were inspected; this is not an actual VoiceOver user acceptance test.
- Runtime preflight passed for 175 hydrated files. Repeated project generation produced the same project hash. The final unsigned generic-iOS Release build succeeded: 0.20.0 (61), expected Bundle ID, compiled new materials and the unchanged privacy declarations. All 59 test launch arguments and seven supplemental test markers checked were absent from its binary; no test bundle is included.

Early checks exposed a too-small center control, fixed-screen test pinch coordinates covered by the new tools, oversized auxiliary glyphs/stairs at maximum text, and expanded hit zones stealing adjacent small images. The product controls/hit priority were corrected; the DEBUG pinch target now follows free canvas and avoids the floating arrangement tools while still using the real UIKit recognizer. Layout, actual gesture, displacement, spending and persistence assertions remain. UIKit's sub-pixel 44-point comparisons use a 0.001-point tolerance. Raw failed and successful runs remain outside Git.
