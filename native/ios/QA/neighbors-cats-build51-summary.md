# 0.14.0（51）邻里拜访与两只新猫

状态：候选版，Release 归档已构建；尚未安装真机、上传 TestFlight 或分发测试。基于独立存档修复 PR #15；本版 PR 的基线为其分支，避免重复审查。网页版没有改动。

## 范围与存档

- 四位本地 NPC、每日首次拜访、重复聊天、四种可购买礼物、喜好加成、每日一次赠礼和五阶段好感度；20/40/60/80 点的阶段奖励与回执一起保存。
- 商店与背包共用紧凑礼物入口，邻居详情收起奖励明细，支持三语与辅助功能字号。新邻里任务沿用现有分页与领取隐藏规则。
- 暹罗猫可可与银渐层霜糖分别有头像、静态图和七套八帧动作，保持原有猫咪尺寸、导航及家具规则。领取后切换、各猫独立状态、图鉴和医院使用同一目录。
- schema 7 为原生 1–6 版补全邻里与礼物数据，保留原进度；当代字段缺失或无效仍拒绝。历史未知邻居、礼物及奖励回执保留，避免以后下线内容导致整档不可读。邻里每日限制与任务共用日期账本，跨时区和回拨不重复刷新。
- 保存成功后才发布扣费、库存、好感和奖励。离开邻里页面后完成写入仍有全局提示；成功提示优先于领养横幅。领养提醒从邻里页打开图鉴时显式清理邻里路由。

## 首轮问题与处理

扩展目录后，Core/旧测试中固定的数量与 schema 夹具需要同步；更新期望后完整 Core 通过。邻里 UI 首轮将本地化金币 `5,000` 错写为 `5000`；只修正测试期望，完整流程复测通过。两猫 Pro 首轮在领养横幅遮住图鉴入口时停止，尚未进入照料动作；用例按实际交互先关闭横幅，再完成两屏复测，未放宽动作阈值。最后复核旧任务 UI 时同步 5/7/10 项每日任务和分页期望；首轮运行仍执行旧数量断言，重新生成该文件的测试编译产物并重装模拟器测试 Runner 后复测。生产奖励与限制未为测试放宽。

默认沙箱下签名信任检查返回 `CSSMERR_TP_NOT_TRUSTED`；在允许访问系统证书的本地校验环境重跑通过。原始日志、xcresult、截图、诊断采样、提示词及生成源文件统一保留在仓库外的 0.14.0-51 产物目录，PR 不包含这些大体积和可能含本机标识的记录；运行美术由 Git LFS 保存。
