# 商店、装备与房间改造 — 0.6.0（28）

2026-11-03。已完成开发、验证、覆盖安装与正常启动确认。安装前后 4,734 字节存档逐字节一致；首次启动被手机锁屏拦截，用户解锁后正常启动成功，已核对安装版本对应的进程，未重复安装。玩家的实际玩法验收待反馈；测试范围内无已知阻断问题。

商店分为用品、家具、装备。用品保留直接购买；四件进阶装备查看条件与效果后购买，进入衣橱手动穿戴，已有工作合约不被重算。绿植和柔软坐垫按独立实例入包，每种商品最多购买 10 件，原有赠送家具不计入。扣款、获得物品与房间升级均经同一保存事务发布，失败不扣款、不发放。

房间升级扩大实际世界与地板几何，猫、食盆和家具的物理显示尺寸仍由原视口决定。归一化布局保留，房间画面可拖动浏览；拖家具至边缘可继续摆到新增空间，“找到猫咪”返回猫咪附近。一级房间映射保持原样。旧存档缺少房间等级时按一级读取；历史超容量布局仍可移动或收纳，不会被截断。正在布置的草稿不会被升级清空。

验证已完成：168 项 Core 测试、30 项 App／场景测试；大小屏 7 个交互方法共执行 14 次，13 次成功。最初一次断言未考虑金额千分位，购买本身正确；调整断言后，完整购买／穿戴／入包／重启流程通过。最终源码上的四次大小屏定向复核全部通过。新几何测试确认新增区域确实可放家具、各级食盆可达、独立实例坐垫的上下垫路线有效；真实 UI 测试将新植物拖到原视口宽度之外，重启后完成碗边进食。
