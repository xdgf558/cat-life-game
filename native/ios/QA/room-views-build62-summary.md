## 变更与依赖

基于 PR #24 的修复提交 `e157be9`，不再与其分别从 main 合并。PR #24 为 0.19.1（61），本 PR 为 0.20.0（62）；三语更新说明与最近三版历史同步，schema 11、Core、网页版、布局存档和物理坐标不变。没有上传或合并。

- 头部与右侧照顾按钮实际测量后留出空间；视角工具和楼梯都避开照顾列，二楼交换左右位置。预览按剩余高度滚动，避免内容过高时反向越过工具栏上边界。
- 换楼层/替换存档后由新场景所有者清理预览，旧回调不能清除新场景状态。空间不足使用单条常驻提示，首次上楼状态可由测试清理。

## 本轮证据与历史失败

运行资源检查175项、资源/工程脚本20项通过。最终未签名 generic-iOS Release 构建通过；最终包为0.20.0（62）、正确Bundle ID；60个UI测试启动参数均未进入Release二进制，没有测试bundle，隐私清单不变，重复生成工程哈希一致。未改或重跑 Core，不把旧版本393项结果算成本次测试。

初轮全量包含302个App用例：298通过，4个方法失败（两处旧楼梯坐标假设、一个亚像素严格比较、一个代理路径重复赋值），并有1个新增UI方法失败。前两项按新的实际布局API与0.001点精度修正，保留避让与节点身份断言；路径赋值已修。

截图复查又发现紧凑卡被误判为底部面板，导致画布被挤小和工具重叠；不能用UI通过代替视觉。改为显式布局状态并合并重复身份卡后，重新验证。

`renderer-coordinate-review-final`：5项App测试通过，包含375×569和402×776、三视角、全屋/放大的真实SKView转换；猫、碗、光圈、名字牌的实测框/锚点与渲染器一致。测试明确只取显示代理，避免 `//` 从整个场景误取模拟节点。

`integrated-small-final`：16项定向App及2项UI通过。`compact-small`的五猫三视角UI通过，但同包换层用例未找到迁入头部的身份分组；修正真实辅助功能分组后，`compact-status-small`的换层用例通过。以上均保留完整原始结果，不冒称整包全部通过或最终源码的同一轮全量运行。

后续 `acceptance-large` 中303项App全量通过；同包成长时间轴/亲密标题及预览换层两项UI通过，另两项UI失败保留在原包中，不把整包说成全绿。最终几行命中范围及辅助呈现修复随后按相关UI流程复测，没有改Core。

`preview-edge-final`：两层五猫/三视角及先近看再点猫两项UI通过。`room-hits-large-final`：iOS 27大屏上述两项及完整楼层升级、真实拖拽保存、商店返回、近看/全屋及冷启动三项UI全部通过。空间不足仍以单条横幅为准。

回归发现并修复两项额外呈现问题：固定头部字号及楼层滚动命中范围越界、44pt找猫图标外溢；以及仅Debug可见的捏合定位辅助元素覆盖预览辅助功能目标。测试定位层在预览期间隐藏，Release无该元素。近看打开预览时也释放已隐藏的顶部紧凑卡空间，底部扩展卡仍保留取景边界。正常用户UI不通过隐藏真实控件来绕过测试。

最终 `scope-label-ax-final`：小屏最大辅助字号下简体、繁体、英文三语流程通过（160.595秒），包含全屋/近看、找猫、视角与上下楼。固定头部按标准最大字号排版，辅助字号下找猫改为带文字的44pt按钮；楼层用 ViewThatFits 优先全称，空间不足时显示1F/2F，朗读标签保留完整楼层名。大字号下房间可视区域会缩小，不把控件可达等同于与正常字号完全相同的取景。

最终 `final-tab-target`：楼层44pt命中形状调整后，预览期间换楼并恢复新楼层状态卡的用例再次通过（37.969秒）。`release-reviewed-final`：最终源码的未签名Release构建通过。

本次共有7个不同UI测试方法的通过记录，分布在上述结果包及 `acceptance-small` 的我的猫咪目录流程中，覆盖成长、预览/换层、五猫三视角、近看直接打开预览、布局保存与冷启动、三语最大字号和猫咪目录；不是同一轮全量UI运行。
