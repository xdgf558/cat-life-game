# 打工养猫日记

原生 HTML、CSS 与 JavaScript 编写的单机生活模拟游戏。直接打开 `index.html` 即可游玩，存档保存在浏览器的 `catGameSaveV1` 中。

## UI 重构

- 使用 Broadsheet 报纸式视觉系统，统一桌面与移动端信息层级。
- 桌面端采用生活、猫咪、猫町和系统四组侧栏；手机端采用五栏底部导航与“更多”页。
- 首页会按猫咪健康、饱食、清洁、玩家饥饿和打工状态生成“今日头条”，喂食与清洁可直接执行。
- 操作反馈统一使用单条快报 Toast，不再常驻堆叠通知。
- 商店接入 20 张压缩商品插画，覆盖全部 25 个商品条目。
- 保持直接 `file://` 打开、原脚本加载顺序和旧存档兼容。
